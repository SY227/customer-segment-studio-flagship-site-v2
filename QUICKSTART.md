# Quick start — v0.3.7

```bash
cd ~/Downloads
unzip -q customer-segment-studio-flagship-site-v0.3.7.zip -d ~/Desktop
cd ~/Desktop/customer-segment-studio-flagship-site-v0.3.7
npm run check
npm test
npm run build
npm run dev
```

Open `http://localhost:3000`.

If port 3000 is already in use:

```bash
PORT=3001 npm run dev
```
